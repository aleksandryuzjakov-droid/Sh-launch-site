Полезно знать.

На какой системе работает лаунчер?

Приложение предназначено для Windows. Рекомендуются Windows 10 или 11 и подходящая для выбранной версии Minecraft Java. Для других ОС сборка здесь не предлагается.

Что входит в скачивание?

Установщик Setup v2 с файлами лаунчера из репозитория проекта. Он позволяет выбрать язык, папку и ярлыки. Игровые файлы Minecraft загружаются отдельно из лаунчера.

Где искать обновления и исходные файлы?

В репозитории SashaLauncher на GitHub ↗. Установщик на этом сайте — включённая в сайт сборка, а не автоматически обновляемая версия.

Windows показывает предупреждение о файле?

Установщик не имеет цифровой подписи, поэтому Windows может показать предупреждение. Проверяй источник и файл антивирусом. Не отключай системную защиту ради установки.
