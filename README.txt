SashaLauncher — статический сайт

Содержимое:
  index.html — главная страница
  style.css — оформление и мобильная версия
  script.js — уведомление о скачивании
  icon.svg — иконка сайта
  downloads/SashaLauncher-Setup-v2.exe — установщик

ЛОКАЛЬНЫЙ ПРОСМОТР
Откройте index.html браузером. Для проверки скачивания лучше запустить
в папке сайта: python -m http.server 8000
и открыть http://localhost:8000.

ПУБЛИКАЦИЯ
Загрузите содержимое этой папки в корень статического хостинга.
Например, GitHub Pages, Netlify или обычный хостинг.
Важно: не забудьте папку downloads. Сборка и Node.js не нужны.
При размещении в подпапке ссылки тоже работают (они относительные).

СКАЧИВАНИЕ
Обе кнопки ведут на downloads/SashaLauncher-Setup-v2.exe.
Это офлайн-установщик Setup v2 из предыдущей сборки,
включающий файлы проекта. Для установки Java и загрузки Minecraft
могут потребоваться отдельные действия и интернет.
Чтобы обновить скачивание, замените EXE, сохранив имя файла,
и при необходимости измените сведения о размере на странице.
Подписывайте EXE цифровой подписью для публичного распространения;
неподписанные установщики могут вызывать предупреждения Windows.

Визуал лаунчера в hero — нарисованный CSS-концепт, не скриншот.
Сайт не реализует запуск игры или авторизацию: это лендинг со скачиванием.
Шрифт Manrope загружается из Google Fonts; при отсутствии сети работает Arial.
Сайт не опубликован автоматически и не имеет подключённой аналитики.
